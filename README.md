# Raiden Shogun Archive
Web & Android app dedicated to Her Excellency, where i pour my all my thoughts about her  
Deployed via https://raiden-shogun-archive.vercel.app/  
and downloadable as Android APK

## What is this?
Raiden Shogun is one of the most complex character in Genshin Impact, yet the most misunderstood within the fandom.  
here i present everything you need to (and must) know to guide you. this blog of mine will be updated regularly by me, the sole admin  

Initially was not intended for public viewing and served only as my private notes, hence the visible admin dashboard button (though i restricted it with password) 

### Contents
- Lore & Story
- In-Game Guide
- Powerscaling Analysis
- Blogs (Thoughts & Theories)
